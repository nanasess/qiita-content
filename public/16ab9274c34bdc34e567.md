2020/8/23 追記

[2.3.5.0 の Edge release で削除されてしまった模様](https://docs.docker.com/docker-for-mac/edge-release-notes/#docker-desktop-community-2350)です。
今後の統合方法を検討するということで、続報を期待します。。

----
[Docker for Mac の Edge channel](https://docs.docker.com/docker-for-mac/edge-release-notes/#docker-desktop-community-2310) で、 [Mutagen ベースのキャッシュ](https://docs.docker.com/docker-for-mac/mutagen-caching/)が使えるようになっています。(手元のバージョンは 2.3.1.0)

従来、 EC-CUBE をはじめとする Symfony をベースとしたアプリケーションや、Composer や npm などのパッケージ管理システムのファイルをマウントすると、[強烈に遅くなる問題](https://github.com/docker/for-mac/issues/2707)がありました。

今回利用できるようになった Mutagen ベースのキャッシュを利用するには、

 1. Preferences -> Resources -> FILE SHAREING でマウントするディレクトリを指定
 2. キャッシュを ON にするだけ。
 
です。
<img width="1152" alt="スクリーンショット 2020-05-24 19.54.49.png" src="https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/40662/f14083cf-275e-217f-d54a-683d41a29dbd.png">


あとは通常通り、アプリケーション全体をボリュームにマウントして大丈夫です。

```shell
## 例
docker run --name ec-cube -p "8080:80" -v "$PWD:/var/www/html:cached" --link container_mysql:db eccube-php-apache
```

以下、手元の環境での比較です。
約7倍にパフォーマンス向上しています。
(性能のよいディスク使っているので、体感的な差は少ないですが、古めの環境では大きく差が出ると思います)

[GitHub の issues](https://github.com/docker/for-mac/issues/2707#issuecomment-631641183) にもパフォーマンス検証結果がコメントされていますので、併わせてご覧ください。

Ruby や Node.js など、 PHP 以外のアプリケーションでもパフォーマンス向上が期待できます。
Docker for Mac の遅さに手を焼いていた方はぜひお試しください！
