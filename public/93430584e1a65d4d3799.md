### 原因

PrimaryKey の CONSTRAINT_NAME と INDEX_NAME が異なる場合は、 プライマリーキーを見つけられないらしい。

以下で検索可能

```sql
SELECT * FROM USER_CONSTRAINTS WHERE TABLE_NAME = '<TABLE_NAME>' AND CONSTRAINT_NAME <> INDEX_NAME;
```

### 解決方法

一旦削除して作成し直せばOK

```sql
ALTER TABLE <TABLE_NAME> DROP PRIMARY KEY;
DROP INDEX <INDEX_NAME>; -- Primary Key の INDEX NAME
ALTER TABLE <TABLE_NAME> ADD PRIMARY KEY (<COLUMN>);
```
