PHP から Oracle へ接続しようとした時、 **ORA-24315: illegal attribute type error** が表示される場合があります。

この場合、 `php.ini` で、どの oci8 ドライバを使用しているか確認しましょう。

```ini
extension=php_oci8_11g.dll   ;; Oracle 11g 以降のバージョンで使用可能
extension=php_oci8.dll       ;; すべてのバージョンで使用可能
```

`php_oci8_11g` を使用している場合は、 `php_oci8` に変更してみましょう。
Oracle11g を使用していても、Oracle Instant Client のバージョンが古いと  `php_oci8_11g` が使用できません。

phpinfo() の **OCI8** の項目に Oracle Instant Client の項目があるので確認してみましょう。

`Oracle Instant Client 10.2` となっていた手元の環境では、 `php_oci8` を使用することにより **ORA-24315** は解消されました。
