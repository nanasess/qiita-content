## Git 超入門

- 使いこなせなくていい(エンジニアでもフルに使いこなしてる人は稀)
- とりあえず今日は2つだけ覚えて帰りましょう
  - `git add` ファイルをリポジトリに追加する
  - `git diff` 差分を確認する

----

# git add と git diff だけで、(とりあえず)差分が確認できるようになります

----

## そのあと覚えるといいコマンド

- `git commit` ファイルを履歴に保存する
- `git log` 履歴を確認する
- `git status` 状況を確認する

----

## 共同作業するためには

- `git branch` ブランチを作成する
- `git checkout` ブランチからファイルを取り出す
- `git push` 履歴をリモートに保存する
- `git pull` 履歴をリモートから取り出す
- `git merge` 履歴を取り込む
