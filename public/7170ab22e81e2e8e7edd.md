EC-CUBE の開発環境作成方法について、いろいろ方法があるのですが、きちんとまとまった記事が無いのでまとめてみます。

*それぞれのメリット・デメリットをもうちょっと詳しく加筆しますのでお待ちください🙏*

- レンサバを直接いじる → おすすめしない
- XAMPP, MAMP → おすすめしない
- ローカルの IIS → 素人にはおすすめしない
- ローカルの Apache や Nginx → 素人にはおすすめしない
- Vargrant → おすすめしない
- Docker → 素人にはおすすめしない
- ビルトインウェブサーバー → おすすめ

ビルトインウェブサーバーが何故おすすめかというと、 EC-CUBE3系と4系は、[1行のコマンドでインストール](https://qiita.com/nanasess/items/debc18697a89a7ccaddb) できるんです。(4系は[こちら](http://doc4.ec-cube.net/quickstart_install#コマンドラインでのインストール))

僕らコアなコミッターも、普段はビルトインウェブサーバーで開発していますので、ちょっと動かす分には全く問題ありませんよ！
